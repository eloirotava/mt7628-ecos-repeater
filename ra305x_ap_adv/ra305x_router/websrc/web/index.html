Wi-Fi networks

Every network is set up the same way. NAT: its own address range with DHCP, behind this device, with the access you allow. Bridge: clients join the Internet side's network and get their addresses from its router. Network 1 always exists; up to 7 networks share the radio.

Saving restarts the device (about one minute). Keep a way back: a NAT network's address, the rescue address 192.168.11.1, or WireGuard.

Administration

These credentials protect this page and Telnet. Telnet is enabled only when an admin password is set and the device network uses WPA2.

Startup script

Console commands run once at every boot, in order, about 20 seconds after start, exactly as typed at the Telnet prompt (for example net route add 10.9.0.0 255.255.0.0 192.168.1.2). Saved without restarting; results of the last boot are shown next to each line.

System

Factory defaults: open network “Extender-<MAC>”, no admin password, Telnet disabled. The reset button does the same when held for more than 4 seconds; a short press restarts.

Firmware update

Upload a firmware image (zxrouter uImage, .img). It is checked first (header, checksums, target). Test in RAM runs it without writing flash: a restart returns to the installed firmware. Install writes only the firmware partition (boot loader, settings and Wi-Fi calibration are kept) and restarts. Do not unplug the device while installing. Requires an admin password.
